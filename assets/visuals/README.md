# Visual assets

These original raster illustrations were generated for ZS API Client with the
built-in OpenAI image generation tool on 2026-08-26. They contain no customer
data, external screenshots, product logos, credentials, or embedded text.

- `zero-trust-hero.png`: wide, dark zero-trust network artwork with a protected
  core, access rings, cloud, endpoint, application, and policy nodes; composed
  with negative space for onboarding copy.
- `security-report-banner.png`: panoramic CISO/SOC report artwork with layered
  policy planes, protected assets, posture signals, and restrained risk accents.
- `investigation-empty-state.png`: transparent investigation evidence map with
  connected endpoint, cloud, application, policy, location, and anomaly nodes.

The shared art direction uses navy, cobalt, cyan, emerald, and limited amber or
coral accents in a polished enterprise 3D style. Prompts explicitly prohibited
people, text, logos, brand marks, watermarks, screenshots, and hacker clichés.
